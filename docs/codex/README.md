# Codex Handoff Folder

This folder is the durable, portable handoff layer for Codex work on Mahita.

Use it for:

- normalized session summaries
- Windows migration notes
- branch-specific stabilization checklists
- links to canonical MahaCharts docs, generated context, and latest audit evidence

Do not treat the Codex desktop app transcript as the source of truth. Raw chat history is app-local and not guaranteed to travel with the repo. The committed files in this folder are the portable record.

## What to update after a meaningful Codex session

1. Add or refresh a dated session handoff note.
2. Link the latest audit artifacts from [docs/internal/generated](/Users/rmehta01/Sites/mahita/docs/internal/generated).
3. Record any new environment or migration assumptions.
4. If the work changed MahaCharts behavior, update the canonical guidebook under [docs/internal/guidebook/mahacharts](/Users/rmehta01/Sites/mahita/docs/internal/guidebook/mahacharts).
