# Evidence Archive

This folder holds historical material that is not part of Mahita's active runtime application.

Use it for:

- early planning notes
- archived status snapshots
- external UI/reference captures
- one-off research artifacts that informed later project decisions

Current archive structure:

- `notes/`
  - historical planning notes and recovered status documents
- `tradingview-research/`
  - captured TradingView reference pages and the original zip archive used for UI research

Runtime code, current docs, and presentation materials should stay outside this archive.
