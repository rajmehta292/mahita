# Development timeline

## Quarter 1

- local Finviz-based concept work
- basic UI and workflow experimentation
- early ML curiosity without a stable experimentation framework
- Raspberry Pi / central-server concept explored and deprioritized

## Quarter 2

- Mahita.ai platform direction established
- user identity and workspace model built
- Schwab onboarding and OAuth account connection integrated
- portfolio/dashboard/active trader/backtester surfaces expanded
- security, auth, admin, and provider-plane hardening work accelerated
- documentation/wiki and presentation-safe demo packaging added

## Most important inflection point

The most important shift was moving from “add more infrastructure” to “stabilize the platform foundation first.” That changed the project from a loosely scoped idea into a more defensible engineering system.
