# Demo mode runbook

Demo mode is meant to make Mahita safe to show on any machine without requiring live credentials.

## Characteristics

- dev-bypass sign-in
- mock Schwab data
- seeded demo users and strategy records
- stable documentation and portfolio surfaces

## Demo sign-in emails

- `owner.demo@mahita.ai`
- `demo.user@mahita.ai`
- `reviewer@mahita.ai`

Passwords are not enforced in dev-bypass mode.
