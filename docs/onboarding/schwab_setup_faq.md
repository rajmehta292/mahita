# Schwab Setup FAQ

## What signs me into Mahita?
Google sign-in authenticates you to Mahita. It creates or reopens your Mahita workspace and preferences.

## What is the Schwab Developer Portal login for?
Use the Schwab Developer Portal to create your API application and obtain the Client ID and Client Secret that Mahita needs.

## When do I log into my real Schwab brokerage account?
After you save the Client ID and Client Secret in Mahita Settings, use the `Connect Schwab` flow inside Mahita. That opens Schwab OAuth, where you sign in with your actual Schwab brokerage account.

## Which credentials do I paste into Mahita?
Paste only the Schwab Developer Portal `Client ID` and `Client Secret` into Mahita Settings.

Do not paste your Schwab website password into Mahita.

## What is the redirect URI for the Schwab app?
Use the production Mahita Schwab callback URL:

- Production: `https://mahita.ai/schwab/callback`

Local developer machines may use separate internal callback settings, but real users should always configure the production URL above.

## Why is Google different from Schwab?
Google signs you into your Mahita workspace. Schwab uses a separate OAuth callback so Mahita can finish connecting your brokerage account after you approve access.

## Why can every user share the same Schwab callback URL?
The callback URL identifies Mahita as the app endpoint. The signed-in Mahita session and the pending OAuth state identify which user started the Schwab connection, so each user keeps separate credentials and tokens.

## Can one Mahita user connect multiple Schwab accounts right now?
Not yet. Today each Mahita user supports one active Schwab brokerage connection. Reconnecting the same Mahita user replaces that user’s prior Schwab authorization.

## Should another user or device ever see localhost?
No. Real users should always authenticate through `https://mahita.ai`. `localhost` is only for internal developer-only testing.

## What are access and refresh tokens?
They are generated by Schwab after the OAuth brokerage connect step. They are not the same as your Client ID and Client Secret.

## What is the provider pool?
The provider pool is an admin-only platform data mechanism. During the current bridge phase, the superuser may explicitly promote one connected Schwab bridge for platform market-data jobs. Normal users do not need to configure this.
