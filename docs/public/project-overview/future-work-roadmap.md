# Future work roadmap

The future roadmap is already clearer than it was at the start of the project.

## Near-term refinement

- continue UI stability work
- improve backtester data quality and strategy runtime behavior
- finish admin/data command hardening
- replace transitional provider bridging with dedicated platform credentials

## Medium-term platform work

- unify backtesting, live monitoring, and deployment under one strategy model
- build a trustworthy strategy promotion workflow from research into live testing
- improve account-level analytics, reporting, and historical performance views

## ML research direction

The ML direction is intentionally framed as a research pipeline, not “AI trading magic.”

The intended framework is:

1. define or import candidate strategies,
2. run systematic tests across many parameter sets and market contexts,
3. compare and summarize results,
4. use the findings to refine strategies instead of blindly optimizing one isolated signal.

This is the longer-term research arc that grows naturally out of the platform that now exists.
