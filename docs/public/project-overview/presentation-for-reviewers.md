# Presentation for reviewers

If you only have enough time to review Mahita at a high level, use this sequence.

## Read

1. `Executive Overview`
2. `Two-Quarter Research Timeline`
3. `Senior Project Report Draft`
4. `Presentation Outline`
5. `Bug And Limitations Appendix`

## Run

If you want to see the project live on a clean machine:

```bash
npm run bootstrap:demo
npm run dev
```

## What you should expect to see

- a functioning signed-in application shell
- demo-safe portfolio, dashboard, and trader surfaces
- a prototype backtester
- a documentation portal with public and signed-in sections

## What you should not expect to see

- a finished institutional trading platform
- final historical data coverage
- a production-grade strategy deployment pipeline
- finished ML-assisted strategy optimization

## Best interpretation of the project

Mahita should be evaluated as a serious full-stack systems project that converged on the correct platform boundaries, not as a finished commercial trading product.
