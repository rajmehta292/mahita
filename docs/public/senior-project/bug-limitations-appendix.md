# Bug and limitations appendix

This appendix is intentionally presentation-safe and honest.

## Current classes of limitations

### Backtesting and strategy runtime

- the current engine remains prototype-grade
- data coverage and strategy-runtime completeness are still improving
- not all live-testing concepts are ready to be promoted directly from research

### UI and workflow polish

- several surfaces are stable but still need refinement
- operator tooling is improving, but not yet complete
- some advanced flows are documented before they are fully productized

### Data and provider architecture

- the platform still has transitional elements such as the temporary provider bridge
- dedicated platform provider credentials are still part of the near-future roadmap

### ML scope

- the ML work is currently at the research/design stage
- the framework direction is defined, but the full experimentation pipeline is not yet finished

## Why this appendix exists

The goal is not to hide constraints. The goal is to show that the system has been evaluated honestly and that unresolved issues already have a documented engineering path forward.
