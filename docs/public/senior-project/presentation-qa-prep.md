# Presentation Q and A prep

## Why did the project change so much?

Because quarter 1 was exploratory. The pivots were a result of understanding the real problem better, not random thrash.

## Is the platform finished?

No. The current result is a functional foundation with clear architecture, trust boundaries, and a disciplined roadmap.

## What is the biggest technical achievement?

Converging on the correct separation between Mahita identity, Schwab authorization, user brokerage access, platform data access, and operator controls.

## Why not finish ML integration?

Because the project first needed a correct platform to host future strategy research. ML without reliable system boundaries and data would have been premature.

## What is the biggest unfinished area?

The backtester and strategy-to-live workflow still need a stronger data model, better data quality, and a more trustworthy execution architecture.

## Why does unfinished work still count as good engineering?

Because understanding constraints, identifying the correct architecture, and documenting the roadmap are real engineering outcomes, especially in a complex system.
