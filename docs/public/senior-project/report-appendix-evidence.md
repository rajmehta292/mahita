# Report appendix: evidence

This appendix summarizes the project evidence that supports the senior-project narrative.

## Week-by-week progression

- early quarter 1: local Finviz prototype and initial UI experiments
- mid quarter 1: exploration of ML ideas without a clear execution model
- late quarter 1: Raspberry Pi and central-controller concept research
- early quarter 2: project reframed around a practical brokerage-connected terminal
- mid quarter 2: Schwab onboarding, auth, and session architecture
- later quarter 2: dashboard, portfolio, active trader, and backtester surfaces
- late quarter 2: admin/control-plane work, documentation system, demo bundle, and evidence export

## Key pivots

- from “many autonomous hardware agents” to “one coherent trading platform”
- from vague ML experimentation to a staged strategy-lab roadmap
- from feature accumulation to trust-boundary and architecture hardening

## Technical milestones

- Mahita user identity and session system
- Schwab developer-key storage and brokerage authorization
- per-user brokerage/account context
- admin control plane and provider-pool bridge
- docs/wiki system
- demo bootstrap and evidence export scripts

## Testing and hardening milestones

- auth routing and health checks
- Schwab OAuth flow hardening
- admin control-plane route isolation
- docs routing, visibility, and browser verification
- demo bootstrap and build verification

## Known gaps

- prototype backtester
- incomplete historical data architecture
- incomplete live strategy deployment model
- incomplete ML strategy-lab implementation
